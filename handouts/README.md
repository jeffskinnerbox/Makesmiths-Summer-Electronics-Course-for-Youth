
Student-facing materials to be printed and handed out in class for the **Summer Electronics Course for
Youth** (Makersmiths course code **ELL-W101**). These are quick-reference aids students keep at the bench,
not lesson plans for the instructor. They are auxiliary materials — *not* outputs of the `.claude/skills/`
pipeline and they do *not* follow the appendix convention — but they must stay factually consistent with
the syllabus, BOM, and lesson plans (component names, class numbering, course code).


| File | Purpose |
| :----- | :-------- |
| `class-02-cheatsheet.md` | Class 2 student cheat sheet — condenses the key ideas into at-a-glance form, e.g. the water-vs-electricity analogy mapping pressure/flow to voltage/current and their measurement units. |
| `class-03-exp-6-manual-switches.md` | Class 3, Experiment 6 (*Very Simple Switching*) — switches, schematic symbols, and reading a circuit as a connection map. |
| `class-03-exp-7-relays.md` | Class 3, Experiment 7 (*Investigating a Relay*) — what a relay is, mapping its pinout with the meter's continuity mode. |
| `class-03-exp-8-relay-oscillator.md` | Class 3, Experiment 8 (*A Relay Oscillator*) — the self-interrupting relay circuit and why feedback makes it buzz. |
| `class-04-exp-9-time-and-capacitors.md` | Class 4, Experiment 9 (*Time & Capacitors*) — charging a capacitor through a resistor to measure time (the RC curve). |
| `class-04-exp-10-transistor-switching.md` | Class 4, Experiment 10 (*Transistor Switching*) — the finger test and using a small base current to control a larger one, with transistor-handling warnings. |
| `class-04-exp-11-light-and-sound.md` | Class 4, Experiment 11 (*A Modular Project*) — the two-transistor oscillator producing a flashing LED and then a tone. |
| `class-05-exp-25-magnetism.md` | Class 5, Experiment 25 (*Magnetism*) — winding an electromagnet on a screwdriver and testing how turn count affects strength. |
| `class-05-exp-28-making-a-coil-react.md` | Class 5, Experiment 28 (*Making a Coil React*) — self-inductance on the breadboard: one LED flashes at switch-on, a second flashes when the collapsing field discharges. |
| `class-06-exp-26-generating-your-own-power.md` | Class 6, Experiment 26 (*Tabletop Power Generation*) — parts list and right-hand-rule notes for the magnet-through-a-coil hand generator. |
| `images/` | Breadboard photos, schematics, and reference figures embedded by the handouts above. |
